# Security policy

The `main` branch is the only supported version. This is a portfolio project with no public deployment. Stripe use is limited to test mode. There is no bounty.

On GitHub, open **Security and quality** and select **Report a vulnerability**. Submit the report privately and keep vulnerability details out of public issues. [GitHub private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected commit, endpoint or component, prerequisites, steps to reproduce, and the expected and observed behavior. Explain the impact and redact credentials and personal data from supporting material.
